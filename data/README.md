# Data directory

This directory contains two kinds of data:

- **Summary tables** (`data/summary/*.tsv`): small, versioned, and meant
  to be committed. They are the reproducibility evidence for the paper.
- **Regenerable outputs** (`data/n*/canonicas.txt`, `data/opt*/n*/canonicas.txt`,
  `data/fibration/*.tsv`): large, gitignored, and regenerated on demand.

## Summary tables (versioned)

| File | Columns | Description |
|---|---|---|
| `summary/class_counts_pl.tsv` | `k, n_orbits, PP, Pp, pP, Ap` | Cell distribution for option 1 (PL) at each level `k` present in `data/`. |
| `summary/class_counts_options_2_8.tsv` | `option, k, n_orbits, PP, Pp, pP, Ap` | Same, for options 2-8. |
| `summary/Nprime_pl.tsv` | `d, N_prime` | Moebius-inverted primitive non-`S3P` orbit count for PL. `N'(d)` is computed from `A'(d) = |Pp(d)| + |Ap(d)|` in `class_counts_pl.tsv` (see Theorem 4 of the paper). |

### How the tables were generated

All three `.tsv` files are produced by:

```bash
python3 experiments/dump_summary.py
```

`dump_summary.py` reads the canonical chains from `data/` (or
`$SW_DATA_DIR`), projects each chain to a word via
`sw.common.chain_to_word`, classifies the word into one of the four
cells (`PP`, `Pp`, `pP`, `Ap`), and writes the aggregated counts.

### caugJAM version

The canonical chains were generated with **caugJAM v0.1.0**
(doi:10.5281/zenodo.23721460) using the pruning method, and verified
against the full method of **canonJAM v1.2.1**
(doi:10.5281/zenodo.23720668) at every level present here. See
`experiments/verify_data.py` for the verification script.

### Verification

```bash
python3 experiments/verify_data.py
```

This loads the versioned `.tsv` files, checks each one against the
expected values from the paper (class counts and `N'(d)`), and (with
`--regenerate`) recomputes them from scratch with caugJAM.

## Regenerable outputs (gitignored)

| Path | Size at high `k` | Regenerated by |
|---|---|---|
| `n{k}/canonicas.txt` | ~100 MB at `k=15` | `caugjam.generate_poda(1, k)` via `sw.common.load_canonical` |
| `opt{op}/n{k}/canonicas.txt` | ~80 MB at `k=9` | `caugjam.generate_poda(op, k)` |
| `fibration/opt{op}/fib_n{k}_n{k+1}.tsv` | a few KB | `caugJAM/scripts/fibration.py` |

These are excluded from version control (see `.gitignore`) to keep the
repository under GitHub's file size limits. They are regenerated on
first use, so a fresh clone will download nothing beyond the summary
tables.

### Regenerating the fibration data

`exp06_fibration_stability.py` and `exp16_forbidden_transitions.py`
require the fibration `.tsv` files. To obtain them:

1. Clone caugJAM: `git clone https://github.com/edgar-castillo-sci/caugJAM`
2. Run `python3 scripts/fibration.py --option 1 --levels 2 3 4 5 6 7`
3. Copy the resulting `data/fibration/*.tsv` into `data/fibration/` here,
   or set `SW_DATA_DIR` to point at a directory that contains both
   `n{k}/canonicas.txt` and `fibration/*.tsv`.

If neither is available, both experiments print a clear message and
exit without error (see `sw.common.load_fibration`).
