# Fibration data

`data/fibration/` holds the parent→child tables for the fibration between
consecutive levels (`k → k+1`). They are used by:

- `experiments/exp06_fibration_stability.py`
- `experiments/exp16_forbidden_transitions.py`

## Why this directory is (almost) empty

The `.tsv` files are **not versioned** (see `.gitignore`), because they
are regenerable and can grow large at high `k`. This README documents
how to obtain them.

## How to obtain the data

The tables are generated by **caugJAM v0.1.0**
(doi:10.5281/zenodo.23721460):

```bash
# 1. Clone caugJAM
git clone https://github.com/edgar-castillo-sci/caugJAM.git /tmp/caugJAM

# 2. Generate the fibration for the option and levels you need
cd /tmp/caugJAM
python3 scripts/fibration.py --option 1 --levels 2 3 4 5 6 7

# 3. Copy the resulting .tsv files here
cp data/fibration/*.tsv ~/Labs/JAM/Stacking_as_words/data/fibration/
```

Alternatively, if you already have the `.tsv` files somewhere, point
`$SW_DATA_DIR` at that directory:

```bash
export SW_DATA_DIR=/path/to/dir   # must contain fibration/*.tsv
```

`sw.common.load_fibration` looks in `$SW_DATA_DIR/fibration/` first,
then `./data/fibration/`.

## File naming

Two layouts are supported:

- `fibration/opt{option}/fib_n{k}_n{k+1}.tsv` (per-option, recommended)
- `fibration/fib_n{k}_n{k+1}.tsv` (flat, option 1 only by convention)

Both are tab-separated. The code does not require a header, but the
generator writes one. Each row is `parent<TAB>child` (two JAM chains).

## Fallback behavior

If no fibration data is found, `load_fibration` returns `None` (or
`(None, "missing")` with `return_source=True`). Both experiments print
a clear message and exit without error:

```
No fibration data found. Generate it with caugJAM's
scripts/fibration.py and place the .tsv files under
data/fibration/ (or set $SW_DATA_DIR).
```
